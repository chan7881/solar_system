# 태양계

COSMIC TRAIL(다른 선생님 작품)의 **태양계 부분만** 떼어 새로 구현하는 3D 웹앱. 수업용(학생이 직접 조작).
원본 분석과 범위는 `원본분석.md`, 이력은 `이력.md`. 원본 사본은 `참고/`(git 제외, 참고용 — 코드·그림을 옮기지 않는다).

## 지금 상태

완료·화면 승인. 테스트 572개 통과(`npm test`). 수치 대조는 각 테스트와 `textures/출처.md`. 저장소 `chan7881/solar_system`(공개). 기능별 완료 기록과 잰 값은 `이력.md`.

- **화면 틀:** 실제 비율 · 행성 8 · 시간 조작(1800~2050) · 이름표 · 날아가기 · 사이드바 · 레이어 창 · 별자리 · 「전체 보기」
- **자세:** 전 천체 IAU 2015 + 계별 주기 항, Horizons 직하점 대조(히페리온만 보기용 회전)
- **지도·모양:** 행성·달·위성·왜행성·혜성 핵 완료(천왕성·해왕성 띠만·태양 표면 단색). 해왕성 대흑점은 1989년 고정 무늬 레이어
- **토성 고리 · 그림자:** Cassini 자료로 비침·그림자(`src/rings_glsl.js`). 레이어 「그림자」를 끄면 고리·토성 그림자가 없어지고 밤면이 밝아진다(지구 구름 그림자는 그대로 — 사용자 결정)
- **위성 22개 · 소천체 · 혜성:** 달은 ELP, 나머지는 Horizons 맞춘 식. 혜성 꼬리·코마(`src/comets.js`) — 한계: 고리는 혜성 꼬리를 가리지 않는다
- **도구:** 거리 재기 · 크기 비교 · 궤도 보기(공전 주기 포함) · 최소·최대 거리
- **왜행성:** 세 왜행성 색을 관측값으로, 하우메아 자세·고리(`src/dwarfs.js`). 한계: 고리→몸체 그림자 없음, 몸체 색에 pV를 램버트 반사율로 넣어 원판 평균이 실제의 약 2/3
- **지구 · 태양:** 밤 불빛 · 대기 빛 · 구름. 태양 렌즈 효과·1/r² 노출 — 행성 여러 개가 한 화면에 든 장면은 아직 안 봄
- **고리 그림자 — 알갱이 무리로 줄이기(2026-11-27):** 고리는 판이 아니라 알갱이 무리라 한 화소에 고리띠·틈이 섞이면 비스듬한 빛은 틈으로 샌다. 예전에는 단면을 줄일 때(밉맵) 정면 빛으로만 평균해, 해가 낮으면(지금 μ0=0.148) 그림자·고리가 꽉 찬 판처럼 검어졌다(μ0=0.1, 1km 칸에서 A고리 그림자 투과 참 0.023 → 0.001). 기울기 8개(μ=1~0.001)의 τ_eff를 따로 줄여 RGBA 두 장에 넣고 1/μ로 보간(`rings.js ringSlantLevels`·`ringSlantTau`, 셰이더 `ringViewSlant`). 칸 안 평균과의 최대 오차 0.04. 화면(2026-11-27 토성, 그림자 화소 35,251개): 투과 평균 0.109→0.144, 상위 10% 0.34→0.43. 테스트 4개 추가 · 변이 4개 모두 잡힘. 남은 근사: 토성 그림자 경계는 반그림자 없이 딱 끊김, 고리 알갱이가 그림자 속으로 흩뜨리는 빛·토성 반사광은 없음
- **선형 합성(2026-11-27):** 본 장면을 `sceneRT`에 선형으로 그려 반투명이 빛 세기로 섞인다(토성·하우메아 고리 `on = L + T·off` 오차 0.0009·0.0017, `tools/check_blend.js`). 표시용 선·점은 예전 밝기 유지(`uiAlpha`), 구름 지도는 선형 분리로 다시 뽑음
- **구름 지도 끊김 수정(2026-11-27):** 햇빛 반사 띠는 NOAA21로 바꿈(띠 자리 구름값 초과 0.148→0.030) · 경도 180° 이음매는 다음 날 영상으로 165~180°를 서서히(양 끝 열 차이/이웃 열 차이 2.7→1.1) · 위도 62~70° 위는 이틀×두 위성 평균(밝기·눈얼음 거르기)으로 네모 조각 없앰(`tools/make_clouds.py`)

- **태양 가장자리 어두워짐·흑점(2026-11-27):** 주연감광 `src/sun.js`(Allen 550nm 2차식, 화면에서 0.9R 0.652·0.98R 0.480 — 식 0.662·0.476). 렌즈 효과 후광은 원반이 커지면 0까지(`flare.js` `BLOOM_NEAR_MIN`=0, 레이어는 켠 채 — 사용자 결정) → 기본 태양 보기(4.3R)에서 후광 0. 흑점은 SDO/HMI HMIIF 2024-04-27~05-23 매일 1장 합성 고정 무늬(`tools/make_sunspots.py` → `textures/sun_spots_2k.jpg`, 원본 `원본/sun/` git 밖). 배치 확인 `tools/check_sunspots.py`: 정면 띠 상관 흑점 있는 날 0.90~0.98, 좌우 뒤집은 변이 0.02. 밝기는 JPEG 영점 I0=0.2로 선형 복원 — 흑점은 실제 비율대로 회색 그대로 두고, 흑점 켜고 끄기 스위치는 만들지 않음(사용자 결정)

- **이아페투스 명암·정반사 끔(2026-11-27):** 지도를 명암이 남은 Cassini PIA18436 밝기로 바꿈(`tools/make_iapetus.py`) — 어두운 쪽 중심/밝은 쪽 반사율 비를 1차 출처 약 1/10에 맞춤(저장한 지도 0.101, 밝은 쪽 밝기는 예전 그대로). 모든 천체의 정반사(F0=0.04, 반사율과 상관없이 약 0.009를 더함)를 꺼 램버트만 남김(사용자 결정) — 화면 보름 위상 정중앙 비 0.117(지도 0.114), 켠 채로는 0.171. 밝은 천체는 약 6% 어두워짐

- **천체 간 밝기(2026-11-27, 화면 승인 대기):** 초점 기준 자동 노출에 반사율 비를 더함(`src/albedo.js`, 사용자 결정). 보는 천체는 화면 평균 반사율 0.23(밝은 곳이 1을 넘는 수성·화성·칼리스토만 낮게), 다른 천체는 (pV 비)×(거리 비)²를 0.1~2.5배로 자름. pV는 NSSDC Fact Sheet(세레스 Reddy 2015, 혜성 핵 0.04, 이아페투스는 밝은 쪽 0.5를 지도에 맞춘 전체 0.33). 지도 통계 `tools/map_stats.py` → `src/map_stats.js`(지도를 다시 뽑으면 다시 돌릴 것). 배율은 `expo`에 곱해 고리·구름·대기 빛이 몸체와 같이 움직이고(토성:고리 비 그대로), 주변광에도 곱함. 지구는 배율 1·화면 평균 0.18(잰 값). 화면 확인 `tools/check_albedo.js`: 단색 구 기준 대부분 ±15%, 토성 엔셀라두스 2.004배·타이탄 0.441배(=pV 비). 테스트 568개 · 변이 5개 모두 잡힘

- **목성형 고리 · 고리 위상 함수(2026-11-27, 「고리 강조」 세기 승인 대기):** 목성(헤일로·주 고리·거미줄 고리)·천왕성(좁은 고리 13개 + 먼지 고리)·해왕성(갈레·르베리에·라셀·애덤스 + 1989년 모습 호) — `src/jovian_rings.js`. 빛 식은 토성과 같고 반사율만 위상각 W(α)(`src/phase.js`): 큰 알갱이(목성 표 · 천왕성·해왕성 램버트 구 ϖ0 0.039) + 먼지(목성 먼지 곡선, 179.5°가 0°의 약 1500배). **토성 고리도 위상 함수로 교체**(Dones 1993 n = 3.301, 화면 70°에서 0.20배·120°에서 0.027배). 실제 밝기로는 안 보이고 레이어 「고리 강조」(처음 끔)가 빛만 목성 ×3만·천왕성 ×30·해왕성 ×300(잠정). 호 경도는 Souami 2022 관측을 빛 시간 빼고 217.74°로 되살림(논문 217.43 ± 0.30°). 테스트 587개 · 변이 7개 모두 잡힘. 한계: 고리 → 행성 그림자 없음 · 고리 원형(천왕성 이심률 뺌) · 헤일로·거미줄 고리 두께 없이 판
- **고리·몸체 밝기 비(2026-11-27, 화면 승인 대기):** 고리는 실제 I/F, 몸체는 지도 값(토성 지도 평균 0.303 — pV 0.499를 램버트로 내려면 0.749)이라 같이 보면 고리가 몸체의 2.1~2.7배(C고리 4.5~6.5배) 밝았다. 고리 빛에 `realToMap`(= (2/3)·지도 평균/pV, 토성 0.405)을 곱하고(목성형·하우메아 고리도), 토성 고리 w를 HST F555W(Salo & French 2010 표 1~3, 기울기 다섯 개)에 맞춤: C 0.25→0.108 · B 0.55→0.592 · 카시니 간극 0.30→0.129(C와 같은 배수) · A 0.45→0.440. 고리/몸체 원반 평균 — 지구에서 보는 각(B=23.6°, α 6°)에서 앱 B 0.86·A 0.62·C 0.10, 관측 0.93·0.59·0.09. 화면 확인 `tools/check_ringglobe.js`(해 쪽 400R·좁은 시야, B=8.5°): 화면 C 0.164·B 0.931·A 0.693, 순수 함수 0.174·0.965·0.718(차이는 몸체 주변광 +3%). 테스트 590개 · 변이 4개 모두 잡힘. 한계: C고리는 기울기가 낮을수록 밝아지는 관측 경향을 덜 따름(B=4.5°에서 0.78배·23.6°에서 1.14배) · 위상각 0° 근처 충 효과(관측 6°→0.3°에서 약 1.35배)는 위상 함수가 1.12배만 · ⚠️ 목성형 고리가 0.28~0.85배로 어두워져 `고리강조_시안.png`는 다시 찍어야 함

## 남은 일

기능 항목은 시안·계획을 승인받은 뒤 진행한다.

1. **고리 강조 세기 승인(다음 차례):** 시안 `고리강조_시안.png`(끔·지금·×4)를 보고 배율을 정한다 → 정해지면 커밋. 결정된 것: 실제 밝기가 기본·강조는 빛만 · 해왕성 호 1989년 고정 · 앞쪽 산란 넣고 토성도 같은 방식
2. **세부 묘사(승인됨 2026-11-27):** 히페리온 지도 여부(전구 지도 공개본 없음 — 만들려면 Cassini 사진을 모양 모형에 투영) · 천왕성 위성 북반구·트리톤 북쪽(관측 없음, 메운 채로) · ~~세레스 색~~ 회색이 맞음(2026-11-27, 0° 위상 반사율 438~653nm 평평 — `textures/출처.md`)
3. **하지 않기로 함(사용자 결정):** 천왕성 세부 묘사

- **카메라가 늘 원점을 보는 것은 아니다** — 궤도 보기가 `controls.target`(바라보는 점)과 `camera.up`을 옮긴다. 거리는 `camera.position.distanceTo(controls.target)`으로 잰다. `camera.up`을 바꾸면 OrbitControls의 `_quat`도 함께 고친다(`setUp`).
- 실행: 폴더에서 `python serve.py`(캐시를 꺼서 브라우저가 옛 모듈을 붙잡지 않는다) → `http://127.0.0.1:8731/` (파일을 직접 열면 모듈이 안 뜬다)
- 단위는 km, **초점 천체가 원점**. 위치는 JS 배정밀도로 계산해 그리기 직전에 초점 위치를 뺀다. 궤도선은 행성 기준 상대 좌표.
- 자동 확인용 `window.__app`(state · step · draw · flyTo · camera · bodies).

## 결정된 것

- 원본 코드·그림을 복사하지 않는다 — 다른 선생님 작품이라서. 수치·그림은 1차 출처(JPL·NASA)에서.
- **크기·거리는 늘 실제 비율** — 「보기 좋은 크기」 모드를 두지 않는다(Eyes 방식, 사용자 결정). 작은 천체는 이름표·동그라미로 찾는다.
- **별 배경은 넣지 않는다**(사용자 결정).
- **딸린 활동(퀴즈·몸무게 계산 등)은 넣지 않는다** — 태양계의 모습을 보이는 시뮬레이션에만 집중(사용자 결정).
